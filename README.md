# تسلق التلال العراقي — Hill Climb Iraq v1.2.0
لعبة سباق تسلق تلال: 60 مرحلة طويلة، 32 سيارة (منها غريبة: ليموزين، صحن طائر، حوض استحمام...) مع تطوير (محرك/إطارات/وقود)، 7 بيئات (مدن وطرق، نخيل، أهوار، ثلج، قمر...)، حركات بهلوانية بمكافآت، صوت، مكافأة يومية، شعار «صنع في العراق».

## بناء ملف APK من GitHub (بدون تثبيت أي شيء)
1. ارفع محتويات هذا المجلد كما هي إلى مستودع GitHub (الفرع main).
2. افتح تبويب **Actions** ← **Build APK** ← انتظر الاكتمال.
3. نزّل **hill-climb-iraq-apk** من Artifacts — بداخله `app-debug.apk` جاهز للتثبيت (أفقي + ملء الشاشة).

## رفع المتاجر
- Uptodown وغيره يقبل الـ APK مباشرة. لـ Google Play تحتاج AAB موقّع: أنشئ keystore وغيّر الأمر إلى `./gradlew bundleRelease` مع التوقيع.
- سياسة الخصوصية: `www/privacy-policy.html` — غيّر البريد فيها، وانشرها عبر GitHub Pages للحصول على رابط.
- الأيقونة: استبدل `www/icon.svg` بأيقونة مصممة، وأضف أيقونات Android عبر `@capacitor/assets` عند الحاجة.

## التحكم
هاتف: النصف الأيمن بنزين، الأيسر فرامل/توازن في الهواء. كمبيوتر: الأسهم أو A/D، و P للإيقاف.
